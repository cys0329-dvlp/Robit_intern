
# AI 활용 내용

## 1. 9×9 배열에 마우스 입력 구현

### 문제
게임 시작 버튼은 콘솔의 특정 좌표 범위를 클릭하면 다음 화면으로 넘어가도록 구현하였습니다.  
하지만 스도쿠는 단순히 좌표를 입력받는 것에서 끝나는 것이 아니라, **클릭한 좌표가 배열의 어느 칸인지 판별한 후 해당 배열에 숫자를 저장해야 하는 문제**가 있었습니다.

### 해결 과정
AI를 활용하여 `windows.h`에서 제공하는 다음 함수들을 알게 되었습니다.

- `GetStdHandle()`
- `GetConsoleMode()`
- `SetConsoleMode()`
- `ReadConsoleInput()`

각 함수의 사용법을 참고하여 마우스 클릭 이벤트를 처리하고, 클릭한 좌표를 9×9 배열의 행과 열 인덱스로 변환하여 원하는 위치에 숫자를 저장하는 기능을 구현하였습니다.

## 2. 스도쿠 중복 금지 및 정답 생성 로직

### 문제
처음에는 1~9의 숫자를 랜덤으로 생성한 뒤, 이미 존재하는 숫자가 나오면 무시하고 다시 생성하는 방식으로 배열을 채웠습니다.

이 방법은 배열을 모두 채울 수는 있었지만, **스도쿠 규칙(행, 열, 3×3 박스의 중복 금지)을 만족하지 못하여 실제로는 정답이 존재하지 않는 퍼즐이 생성될 가능성이 매우 높았습니다.**

### 해결 과정
AI를 통해 스도쿠 생성 알고리즘의 아이디어를 얻어 다음과 같은 함수들을 작성하였습니다.

- `is_valid_EASY()`
  - 현재 위치에 숫자를 넣을 수 있는지 검사
  - 행, 열, 3×3 박스의 중복 여부 확인

- `shuffle_numbers_EASY()`
  - 1~9 숫자의 순서를 무작위로 섞어 다양한 스도쿠가 생성되도록 구현

- `fill_board_EASY()`
  - 백트래킹(Backtracking) 알고리즘을 이용하여 규칙을 만족하는 스도쿠 정답판 생성

이를 통해 **항상 스도쿠 규칙을 만족하는 올바른 정답 배열을 생성할 수 있도록 구현하였습니다.**
